## Evidence and reproduction

Sanitized machine results are in [evidence/framework-helpers.json](evidence/framework-helpers.json), including the final Playwright totals, eight consumer results, three production builds, package hash, bundle totals and observed cleanup. Raw test output is ignored under `output/`.

Reproduce from source with frozen install, `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm build`, `pnpm build:next`, `pnpm build:frameworks`, `pnpm check:bundle`, `pnpm test:package`, then `pnpm exec playwright test --project=chromium --project=firefox`. The isolated SSR install directories were removed after verification; `build:frameworks` regenerates them. The SDK tarball remains under `output/packages/` for integration.

The milestone makes no claim of every framework release, Angular SSR application acceptance, Safari/WebKit acceptance, distributed service failover or public registry availability. Existing unsupported DOM boundaries and URL/privacy restrictions remain documented in the integration/reliability guides.
