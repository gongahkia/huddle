# Local/team mode release verification — 15 November 2026

Both private packages are 0.4.0. This release adds an explicit browser-local adapter, retains the host-backed team adapter and uses the same discussion, validation and transfer engine for both. Host entry points retain native Node cryptography; browser-local hashing uses pinned @noble/hashes 2.4.0. Zod Mini 4.6.7 replaces the full shared validators; regenerated JSON/OpenAPI schemas have no diff. Existing database schema version and wire contract remain unchanged.

The visual workbench and its fictional host now live in `examples/testing/playground/`, run with `pnpm examples:playground`, and retain `/playground/` page identities. It is an example/testing surface, not an installed product. `examples/local/` separately runs with a static asset server and no review API/database service. The previous manually launched workbench process was already stopped when checked; this work did not reset or seed a real feedback store.

Verified on Node 24.21.0, pnpm 10.33.0 and Playwright 1.65.0:

- Frozen installation, typecheck, lint, 143 unit tests, build and bundle checks passed. The main rebuilt browser run passed 163 tests with two intentional Chromium-only metric skips on Firefox/WebKit. Nine additional installer/CSP/local-tab tests passed on all three browsers. The initial installer test used the fixture marker rather than the live document nonce; reading the actual nonce corrected that fixture without loosening CSP.
- The installed private archive passed team and local lifecycle/runtime checks for HTML, React/Next.js, Preact, Vue/Nuxt, Svelte/SvelteKit, Solid, Angular and Astro, plus actual jQuery/htmx interaction pages. All eleven maintained HTML/framework fixtures were rebuilt from the tarball. Native local cases cover reload/detach retention, generated names, clipboard/selection fallback, colors, paging, concurrency, conflicts, idempotency, consistent export during writes, resumable/repeated imports, provenance, storage capacity/cancellation/denial and local↔real-host transfers. The standalone team/local installers also passed with the host's actual CSP nonce.
- Native database conformance/portability passed 41 SQLite tests and 170 PostgreSQL/MySQL/MongoDB/ordered-portability tests. All twelve Next.js/Express/Fastify × SQLite/PostgreSQL/MySQL/MongoDB combinations passed authenticated HTTP/transfer, restart persistence and uninstall/data-retention checks. These use marked disposable fixtures and native PostgreSQL 18.6, MySQL 8.4.13 and MongoDB 8.0.38; no application database or inference worker is involved.
- Ten isolated browser consumers, including a complete local-widget import graph, and the SQLite host consumer passed independent install, declaration, SSR import and bundling/persistence checks. The browser archive tested by that gate had SHA-256 `19cc059ef3e45b2cdef4b967033567c3d66daf7f9b730656f0f8c3bb0ba9c98a`; consumer rollout must record the checksum of its actual final packed archive separately.

The complete local ESM widget graph is 59,886 bytes gzip; standalone local installer 59,327; team installer 32,613; core graph 31,436; HTTP graph 3,098; local adapter graph 28,927. Each and the combined local widget remain below 76,800 bytes. Framework consumer totals include their selected framework runtimes and are not the SDK-only measurement. Third-party license notices ship with the browser package.

The full resource suite sampled twenty mount/destroy cycles per browser, fifteen-second closed windows and 120 seconds of open review in Chromium/thirty seconds in Firefox/WebKit. Chromium retained 984,732 heap bytes after cleanup with zero listener delta; all browsers measured zero closed requests and six requests per thirty-second open window. Equivalent Firefox/WebKit heap/listener metrics are unavailable. Exact runtime reports, bundle metadata, package provenance, snapshots and logs remain under ignored `output/modes-release`, `output/browser`, `output/package` and `output/server-matrix`. Clipboard permissions, eviction/private-browser policies, screen readers, every browser/device version and hours-long performance remain outside these bounded samples; local IndexedDB is not a cross-device backup or team service. See [local installation and limits](local-review.md).
